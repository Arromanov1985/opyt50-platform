2. Какие данные обрабатываются

  • Для аккаунта: имя, email, защищённое представление пароля, сеансы входа.
  • Для соискателя: профессия, город, навыки, зарплатные ожидания, условия занятости, опыт, образование, достижения, история откликов и согласий; телефон только при его указании.
  • Для работодателя: имя представителя, компания, email, опубликованные вакансии и история взаимодействий.
  • Для обращений: текст обращения и контакт для ответа; для безопасности — необходимые технические события.
  • Для аналитики журнала — агрегированные суточные показатели без идентификатора посетителя в приложении; состав и сроки хранения серверных логов [ПРОВЕРИТЬ У ХОСТЕРА].

Сайт не предназначен для сбора сведений о здоровье, интимной жизни, политических взглядах и других специальных категориях данных. Не указывайте их в свободных полях.

3. Цели и основания

  • Предоставление аккаунта, поиск и отклики: обработка, необходимая для договора с пользователем либо его заключения по инициативе пользователя, в пределах ст.6 152-ФЗ; соответствие конкретных операций этому основанию [УТВЕРДИТЬ].
  • Передача кандидатом контактов конкретному работодателю: только в рамках отдельного информированного согласия или иного подтверждённого правового основания; получатель, цель и объём сообщаются кандидату до раскрытия.
  • Сервисные письма и безопасность: исполнение обязательств и установленные законом требования.
  • Реклама и маркетинговые рассылки: без отдельного добровольного согласия не используются.

4. Кому и как предоставляются сведения

Профессиональные сведения используются для работы сервиса с ограничением доступа. Личные контакты кандидата не должны быть доступны работодателю до предусмотренного отдельного подтверждения. Передача данных в открытый интернет для неопределённого круга лиц без надлежащего основания не допускается.

Технические обработчики (хостинг, PostgreSQL, резервное копирование, служебная почта): [ОПИСАТЬ ПО ФАКТИЧЕСКИМ ДОГОВОРАМ]. Территория хранения и возможность трансграничной передачи: [ПОДТВЕРДИТЬ ПО КАРТЕ ИНФРАСТРУКТУРЫ].

5. Сроки обработки и безопасность

Хранение допускается только в пределах согласованных целей и сроков, установленных законом или необходимым договором. Сроки по категориям, резервным копиям и служебным журналам [УТВЕРДИТЬ]. Применяются контроль доступа, защита соединения, защита паролей, ограничения сессий и меры реагирования на нарушения; точный перечень мер [СВЕРИТЬ С РЕАЛЬНОЙ ИНФРАСТРУКТУРОЙ].

Пользователь вправе обратиться за информацией о своих данных, их исправлением, блокированием, прекращением обработки или удалением при наличии законных оснований, а также отозвать согласие. Отзыв не прекращает автоматически обработку по иным правомерным основаниям.
