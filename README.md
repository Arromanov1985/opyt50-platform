# ОПЫТНО.РФ — MVP 0.2 (в разработке)

> **Важно:** Релиз 0.2 пока находится в отдельной ветке `feature/release-0.2-job-search` и draft PR. Рабочая ветка `main` и Timeweb preview не изменены. Для пользователей доступны только вымышленные данные.

### Что добавлено в 0.2
- Поиск по профессии, городу, зарплате и графику, отдельный экран подробной вакансии.
- Самостоятельный отклик кандидата, история, статусы, отзыв заявки.
- Избранные вакансии и контроль дубликатов.
- Для работодателя — обезличенные отклики на свои вакансии и статусы.
- Для администратора — управление активностью обычных пользователей и статусами вакансий, журнал действий.
- Тестовая очередь уведомлений для регистрации, откликов, приглашений и изменения статуса; **реальной отправки писем нет**.
- API и экран восстановления пароля, подтверждение email через одноразовый токен; до подключения email-провайдера это тестовый сценарий. Верификация пока не блокирует вход.
- Отдельные стили и JS-модуль релиза, сохраняющие брендбук и функции предыдущей версии.

**Полное ТЗ и критерии приёмки:** [docs/RELEASE_0_2_SPEC.md](docs/RELEASE_0_2_SPEC.md).

### Как принять релиз безопасно
1. Запустить `python -m pytest -q` и `node --check app/static/release02.js` (GitHub Actions автоматически проверяет оба).
2. Проверить вручную с вымышленными кандидатами и работодателями: поиск → избранное → отклик → изменение статуса → история.
3. Проверить восстановление доступа через тестовую очередь из локальной БД, блокировку и разблокировку пользователя, сохранность исходного процесса приглашения.
4. Решить, где просматривать ветку (локальный запуск / согласованный временный тестовый стенд). **Не переключать работающий Timeweb без явного согласования.**
5. После приёмки перевести PR из draft в ready и только затем объединить изменения с `main`.

# ОПЫТНО.РФ — описание базового MVP 0.1

**Ваш опыт работает на вас.** Первый работающий прототип сервиса поиска сотрудников и вакансий с акцентом на квалификацию и опыт, а не возраст. Сервис доступен людям любого возраста. Интерфейс — на русском языке.

### Уже работает

- Регистрация, вход, выход и отдельные роли **соискателя / работодателя / администратора**.
- Кабинет кандидата: профессия, навыки, город, зарплатные ожидания, график, занятость, контакт.
- Кабинет компании: публикация, закрытие и открытие вакансий; список совпадений.
- **Подбор кандидатов без возрастных фильтров**: жёсткая проверка города, зарплаты, графика и занятости; объяснимые баллы за профессию и навыки.
- Приглашения кандидата, подтверждение или отказ; **отдельное согласие** на открытие имени и контактов выбранной компании.
- **Тестовая оплата** знакомства: имитация, без реального списания. Контакты скрыты до согласия и тестового подтверждения; повторная транзакция не создаётся.
- Статистика администратора, адаптивный интерфейс, простое REST API (`/api/docs`).

### Быстрый запуск на Windows (PowerShell, Git Bash) и Linux

Требуется **Python 3.11+**. Выполняйте из корневой папки проекта:

```bash
python -m venv .venv
```

Активируйте окружение: **PowerShell:** `.\.venv\Scripts\Activate.ps1`, **Git Bash:** `source .venv/Scripts/activate`, **Linux/macOS:** `source .venv/bin/activate`.

```bash
python -m pip install -r requirements.txt
python scripts/seed_demo.py
python -m uvicorn app.main:app --reload
```

Откройте **http://127.0.0.1:8000**.

Пользователи с полностью вымышленными данными для локального тестирования:

| Роль | Email | Пароль |
|---|---|---|
| Работодатель | `company@demo.example` | `DemoPass2026!` |
| Кандидат | `kladovshik@demo.example` | `DemoPass2026!` |
| Администратор | `admin@demo.example` | `DemoPass2026!` |

В демобазе четыре вакансии. Начните с работодателя и вакансии «Кладовщик»: нажмите **«Подобрать кандидатов» → «Пригласить»**. Выйдите, зайдите кандидатом и согласитесь на приглашение. Вернитесь в кабинет работодателя и нажмите **«Тестовая оплата»** для открытия контакта. **Никаких реальных платежей не происходит**.

`seed_demo.py` отказывается добавлять демопользователей в непустую БД; никогда не запускайте его в производственной среде.

### Запуск без демоданных

Не выполняйте `seed_demo.py`. Запустите сервер и создайте пользователей через веб-интерфейс. Администратор не создаётся через публичную регистрацию. Для реального запуска требуется отдельная безопасная процедура создания администратора.

### Тестирование

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
node --check app/static/app.js
```

Тесты проверяют регистрацию, роли, защиту мутирующих запросов, приватность профилей, ограничения работодателей, подбор, приглашения, согласие на передачу контактов, демонстрационную оплату, отсутствие дублирующихся транзакций и отсутствие возрастного скоринга.

### Архитектура

```text
app/main.py                 HTTP API, проверки доступа, workflow
app/db.py                   SQLite и схема данных
app/security.py             PBKDF2 и отзывные HttpOnly-сессии
app/matching.py             правила и объяснимый скоринг
app/static/index.html       адаптивный интерфейс
app/static/styles.css       дизайн-система
app/static/app.js           UI и взаимодействие с API
scripts/seed_demo.py        вымышленные локальные данные
tests/test_mvp.py           интеграционные тесты
.github/workflows/tests.yml CI
```

Стек: **Python / FastAPI / SQLite / vanilla JavaScript / CSS**. Не требует Node, npm или внешних AI-сервисов для запуска. За счёт разделения frontend/API/подбора позже можно подключить PostgreSQL, Yandex SpeechKit, ИИ-интервью, SMS и эквайринг.

### Границы MVP — прочтите перед публикацией

1. **Платежи только демонстрационные.** В API нет настоящего эквайринга, онлайн-кассы, закрывающих документов, возвратов и биллинга. Не принимайте оплату от реальных клиентов через MVP.
2. **Не размещайте реальные анкеты и контакты** до реализации обязательных юридических и технических процедур: политики обработки ПД, надлежащих согласий, локализации, HTTPS, аудита доступа, проверки операторов/подрядчиков и хранения логов. Согласие внутри демонстрации не заменяет юридически выверенные документы.
3. **Секреты и базы не коммитить.** `.gitignore` исключает `.db`, `.env`, `.sqlite*`; репозиторий может быть публичным, но данные пользователей — нет. Демо-логины строго для локального теста.
4. **Для продакшена** требуется PostgreSQL, распределённое ограничение частоты запросов, мониторинг и резервное копирование, верификация телефонов, антифрод, политика удаления данных, аудит авторизации, тестирование безопасности и размещение на подходящей инфраструктуре в РФ. Установите `OPYT50_COOKIE_SECURE=1` за HTTPS.
5. **Не внедрено:** настоящий ИИ, автоматический звонок, произвольный поиск соискателей, интеграции с hh.ru, реальная платёжная система, договоры и юридическое сопровождение.
6. Цена знакомства в демо рассчитана по типу вакансии, без учёта возраста кандидата: рабочие — 1490 ₽, специалисты — 2990 ₽, руководители — 7900 ₽. Суммы — продуктовые гипотезы.

### Тестовая публикация на Timeweb Cloud

Подробная пошаговая инструкция: **[DEPLOY_TIMEWEB.md](DEPLOY_TIMEWEB.md)**.
Для показа тестового стенда через App Platform предусмотрены защита паролем `OPYT50_PREVIEW_PASSWORD` и необязательная загрузка вымышленных данных `OPYT50_PREVIEW_SEED_DEMO=1`. Пароль задаётся только в настройках Timeweb Cloud; не храните его в GitHub.

Для доступа к сайту сначала введите логин предпросмотра `review` (либо установленный в `OPYT50_PREVIEW_USERNAME`) и секретный пароль предпросмотра, затем можете входить под демонстрационным пользователем в самом приложении.
