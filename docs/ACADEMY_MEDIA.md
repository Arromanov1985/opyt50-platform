# Академия СТАЖНО: мультимедийные материалы

## Первый этап — приватный карантин

Модуль `app/academy_media.py` реализует ограниченную по размеру загрузку в
приватное S3-совместимое хранилище через серверный клиент. Он не подключён к
HTTP и не публикует объекты. Проверка сигнатур и структуры ZIP является
предварительной, не антивирусной проверкой.

| Материал | Форматы первого этапа | Максимум на файл |
|---|---|---:|
| Изображение | JPEG, PNG, WebP | 10 МиБ |
| Аудио | MP3, WAV, M4A | 80 МиБ |
| Видео | MP4 | 300 МиБ |
| Документ | PDF | 25 МиБ |
| Презентация | PPTX | 50 МиБ |

Форматы и лимиты — начальные технические параметры, подлежат согласованию
с квотами и фактическим хранилищем.

## Условия подключения к конструктору

1. Приватный бакет, серверные ключи с минимальными правами, проверка запрета
   анонимного доступа и ограничение расходов/квот. Никаких ключей в Git.
2. Таблица метаданных в PostgreSQL: уникальный идентификатор, владелец,
   курс, контрольная сумма, размер, тип, состояние проверки; связь с
   черновиком и отдельным опубликованным снимком курса. Загрузка только
   владельцем или редакцией в рамках действующей сессии, CSRF-защиты,
   ограничения обработки данных и контроля версий.
3. Карантин с антивирусной проверкой, полноценной декодировкой и безопасной
   обработкой изображений/аудио/видео/документов. Ошибка проверки запрещает
   публикацию. PDF и PPTX не исполняются и не встраиваются как активный HTML.
4. Выдача файлов через контролируемый серверный маршрут с проверкой доступа:
   автор — собственный черновик, редакция — допустимый курс на проверке,
   читатель — только материал, входящий в действующий опубликованный снимок.
   Отзыв публикации, отзыв согласия, ограничения данных и удаление аккаунта
   прекращают выдачу. Не использовать постоянные публичные URL бакета.
5. Безопасное удаление, учёт срока хранения, очистка потерянных/устаревших
   объектов после проверки ссылок, журнал событий без содержания файлов,
   тесты PostgreSQL и миграций.
6. Интерфейс конструктора: загрузка с прогрессом, порядок блоков, удаление,
   доступный предпросмотр, описание изображения, текстовая расшифровка
   видео/аудио. Мультимедиа не заменяет текст урока, практику и самопроверку.
   Сохранение старых текстовых курсов и их прогресса.

## Статус

Фундамент приватной загрузки, реестр файлов в SQLite/PostgreSQL, квоты
и учёт резервирования до записи объекта реализованы. Реестр включён в
миграцию и оценку запроса на прекращение обработки данных. Выгрузка
метаданных не содержит ключей хранилища и не является выгрузкой файлов.
Резервирование и завершение загрузки выполняются отдельными транзакциями:
при сетевом сбое остаётся запись с ключом для будущей сверки.
Удаление курса с записью файла блокируется внешним ключом, чтобы не потерять
учёт объекта. Сначала требуется подтверждённое удаление объекта.
Подключение реального бакета, антивируса, удаления объектов, HTTP-маршрутов,
ссылок уроков на файлы и редактора ещё не выполнено.
Юридическая блокировка публичного запуска остаётся без изменений.


## Серверное подключение S3

Модуль `app/academy_storage.py` загружает настройки только при явном
`STAZHNO_ACADEMY_STORAGE_ENABLED=1`. Дополнительные зависимости:
`pip install -r requirements-academy-storage.txt`.

| Переменная окружения | Назначение |
|---|---|
| STAZHNO_ACADEMY_STORAGE_ENABLED | Явное разрешение создания клиента (по умолчанию 0) |
| STAZHNO_ACADEMY_S3_ENDPOINT | HTTPS endpoint приватного S3-провайдера |
| STAZHNO_ACADEMY_S3_REGION | Регион подписи S3 |
| STAZHNO_ACADEMY_S3_BUCKET | Имя приватного бакета |
| STAZHNO_ACADEMY_S3_ACCESS_KEY | Серверный ключ доступа |
| STAZHNO_ACADEMY_S3_SECRET_KEY | Серверный секрет |

Конфигурация не создаёт клиент при выключенном флаге. При неполных или
небезопасных настройках она завершает операцию ошибкой. TLS-проверка
не отключается. Запись использует `If-None-Match: *`: существующий объект
нельзя перезаписать повторной загрузкой. Перед подключением требуется
проверить поддержку этой операции конкретным S3-провайдером, отсутствие
анонимного доступа, правила версионирования и жизненного цикла, квоты и
стоимость. Если провайдер не поддерживает условную запись, загрузку
не включать без равноценной защиты от перезаписи.

Этот флаг не открывает HTTP-маршруты. Они по-прежнему отсутствуют.


## Проверка карантина

Модуль `app/academy_media_scan.py` считывает именно зарегистрированные байты,
сверяет размер и SHA-256, передаёт их локальному ClamAV через Unix-сокет
(INSTREAM, ограничение времени и ответа). Ошибка сервиса, превышение лимита,
неверная контрольная сумма или неизвестный ответ не разрешают публикацию.
Статус clean требует ещё независимой проверки формата; сейчас предусмотрен
декодер неподвижных JPEG/PNG/WebP через Pillow (до 20 млн пикселей).
Для остальных форматов обработчик отсутствует и результат fail-closed.
Даже clean не разрешает выдачу оригинала из карантина.
Результат сохраняется только для неизменённой записи pending; устаревший
результат не восстанавливает отозванный файл.

Перед вводом в эксплуатацию нужно развернуть и проверить ClamAV, обновление
сигнатур, фактические лимиты INSTREAM/архивов и изоляцию обработчиков,
подключить нормализацию файлов, управляемый worker и безопасную выдачу.
Проверки в CI используют имитацию хранилища и ответов clamd, а не реальный
бакет или антивирусный сервис. Не включать загрузки до завершения этих работ.


## Черновики уроков

Урок поддерживает упорядоченные ссылки на записи реестра курса, подпись,
альтернативное описание и расшифровку. Редактор позволяет добавлять
доступные записи, менять их порядок, убирать связь с уроком и видеть
текстовый предпросмотр. Чужие, неизвестные или удаляемые записи отклоняются.
Имена ключей и контрольные суммы не передаются редактору. Модератор видит
метаданные только разрешённого снимка. Текстовые курсы сохраняют прежнюю
структуру JSON, а изменение черновика не затрагивает предыдущую публикацию.

Ограничение текущего этапа: публикация любых черновиков со ссылками на
файлы запрещена до реализации безопасной выдачи. Даже статус clean сам
по себе не разрешает публикацию. В интерфейсе явно указано, что загрузка
и воспроизведение ещё не подключены.


## Закрытая загрузка и предпросмотр изображений

Экспериментальный вертикальный цикл поддерживает только JPEG, PNG и WebP
до 10 МиБ. Для включения требуются все настройки S3 из предыдущего раздела,
`STAZHNO_ACADEMY_IMAGE_UPLOAD_ENABLED=1` и
`STAZHNO_ACADEMY_CLAMD_SOCKET=/путь/к/clamd.sock`.
Без обоих флагов и полной конфигурации маршруты не выдают файлы.
Перед включением подтвердить доступность ClamAV, приватность бакета,
неперезаписываемость объектов, квоты хостинга и настройки прокси.

Загрузка использует raw-body с точным Content-Length, без multipart;
аутентификация, CSRF, текущая версия курса, контроль владельца и лимит
частоты обязательны. Увеличение лимита тела касается только этого маршрута.
Резервирование фиксируется до передачи в S3, не удерживая транзакцию БД
во время внешней операции. При неизвестном исходе остаётся запись.
Загрузка ещё не означает разрешение на просмотр.

Обработка: `python -m scripts.scan_academy_media --limit 10` из доверенной
среды с DATABASE_URL и приватным сокетом ClamAV. Одна ограниченная партия,
без автоматического планировщика. Запускать одним worker; ошибки требуют
операторского контроля и будущего механизма повторной проверки/очистки.

Приватный предпросмотр проверенного изображения доступен после сохранения
его связи с черновиком. Сервер повторно проверяет размер и SHA-256, создаёт
новый JPEG до 1600 px без исходных метаданных, затем повторно проверяет
доступ перед ответом. Оригинал не возвращается. Публичное воспроизведение
и публикация мультимедиа по-прежнему запрещены. Аудио, видео, PDF и PPTX
не принимаются этим HTTP-маршрутом до реализации их безопасной обработки.

Ограничение по параллельности действует на процесс приложения. Перед
реальным включением необходимы глобальная квота хранилища, лимиты прокси,
контроль расходов, автоматическая обработка и сверка/удаление зависших
объектов. Не считать тесты с имитацией S3/ClamAV проверкой инфраструктуры.


Интерфейс автора: выбор изображения, процент передачи через XHR, отдельный
статус ожидания подтверждения, автоматическое добавление ссылки в черновик,
обновление статусов без потери несохранённого текста. При изменении версии
в другой вкладке обновление реестра не заменяет черновик. Предпросмотр
показывает только серверное нормализованное изображение из сохранённой связи.


## Изолированная подготовка аудио, видео и PDF

Добавлен модуль `app/academy_conversion.py`. Он принимает локальный поток
уже проверенного исходника в отдельном обработчике и создаёт новые копии:

- MP3, WAV, M4A → AAC в M4A, до 30 минут;
- MP4 → H.264/AAC, до 1280×720 и 15 минут;
- PDF → упорядоченные JPEG-страницы, до 30 страниц и 1600 px на сторону.

Исходные метаданные, дополнительные дорожки и главы не передаются в копию.
Неподдерживаемые дорожки, превышение длительности/размера, ошибки декодирования
и неполный результат отклоняются. Команды выполняются без shell, с фиксированными
параметрами, без наследования окружения и с ограничением времени. Выходные
файлы создаются только в отдельном пустом каталоге задания.

**Модуль не является песочницей.** Запускать только внутри изолированного
контейнера/worker без сети, секретов, доступа к БД или другим файлам,
с read-only rootfs и ограничениями RAM, CPU, PID и временного диска.
Сервис с S3/БД передаёт ему копию проверенных байтов. До регистрации
проверенного результата и реализации контролируемой выдачи он остаётся
внутренним инструментом. HTTP-загрузка новых форматов и публичная выдача
по-прежнему отключены. Для PPTX потребуется отдельная изоляция конвертера.
В CI предусмотрена отдельная проверка на настоящих FFmpeg и Poppler,
использующая только синтетические файлы.
