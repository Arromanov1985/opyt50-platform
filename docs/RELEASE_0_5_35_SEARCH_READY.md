# Релиз 0.5.35 — проверка публикации Журнала и готовность к поисковому трафику

Дата подготовки: 19 ноября 2026 года. Базовый релиз: 0.5.34.

## Зачем это нужно

После добавления Журнала 0.5.34 GitHub проверял точное совпадение основных JS/CSS и старых API-маршрутов, но не проверял точные HTML-страницы статей. При этом продвижение контента в поиске имеет смысл только после подключения основного домена.

## Реализация

1. `GET /sitemap.xml` — только главная страница, список статей и три одобренных материала; никаких резюме, аккаунтов и персональных данных.
2. `GET /robots.txt` — для `stazhno.ru` и `www.stazhno.ru` разрешается индексация публичных страниц и указывается sitemap; для временного домена Timeweb и неизвестных host — `Disallow: /`.
3. Заголовок `X-Robots-Tag: noindex, nofollow` на временных/неизвестных доменах предотвращает индексацию технического превью независимо от содержимого `robots.txt`.
4. Проверка публикации **сверяет побайтово** четыре публичные страницы Журнала с рендером текущего GitHub-коммита. Отсутствующие, устаревшие или защищённые паролем страницы не отмечаются как опубликованные.
5. Итог GitHub Actions содержит строку «Журнал (все страницы)».
6. Новые тесты проверяют read-only GET без cookies, sitemap, заголовки индексации, HTTP-методы, точность HTML и отсутствие пользовательских данных.

## Что не делаем

- Не подключаем домен и не меняем DNS без отдельного решения.
- Не отправляем сайт на индексацию в Яндекс Вебмастер до готовности основного домена и проверки контента.
- Не вводим пользовательское поведенческое отслеживание, аналитические cookies или новые таблицы БД.
- Не меняем сценарии откликов, соглашения о раскрытии контактов и действия работодателей.

## Приёмка

- Python/API, браузерные smoke, PostgreSQL, CodeQL — зелёные.
- Проверить `GET /journal` и три статьи на Timeweb после merge.
- Проверить, что на техническом домене возвращается `Disallow: /` и `X-Robots-Tag: noindex`.
- Проверить, что `sitemap.xml` содержит только 5 публичных страниц.
- Убедиться, что фактически опубликованная версия совпадает с `main`.

## Дальнейшие действия по стратегии

После стабилизации Журнала перейти к измерению воронки контент → вакансии → профиль (с учётом правил персональных данных), интервью с пользователями и подготовке следующих 7–12 материалов. Это **не заменяет** утверждённую стратегию `STAZHNO_STRATEGY_90_DAYS.md`.
