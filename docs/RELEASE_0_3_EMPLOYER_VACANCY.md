# ОПЫТНО.РФ — итерация 0.3: публикация вакансий работодателем

## Цель и пределы
Упростить создание вакансий: работодатель отвечает на короткие вопросы, видит итоговый текст со стороны соискателя и публикует его только после проверки.

- Основа: `feature/release-0.3-accessible-onboarding` (прошлая задача — помощник соискателя).
- Рабочая ветка: `feature/release-0.3-employer-vacancy-preview`.
- **Не объединять с `main`**, не переключать Timeweb до согласования.
- Использовать только вымышленные данные; никаких реальных платежей, email/SMS и дополнительных платных сервисов.

## Функциональная спецификация
1. **Основная информация**: должность (обязательно), город/удалённо (обязательно), ключевые навыки, диапазон зарплат, график, занятость.
2. **Описание**: три отдельных обязательных текстовых поля с понятными примерами: обязанности (до 400 символов), требования (до 300), условия работы (до 350). Подсказка предупреждает против возрастных ограничений. Содержимое ничем не дополняется автоматически.
3. **Предпросмотр**: до публикации кнопка показывает полное объявление — компанию, должность, зарплату, город, график, навыки и описание из трёх разделов. Пользователь видит окончательный текст до передачи в API.
4. **Контроль изменений**: до предпросмотра «Опубликовать» неактивна; изменение любого поля после предпросмотра закрывает его, отключает публикацию и требует повторной проверки.
5. **Валидация**: обязательные поля заполнены; зарплата «до» не меньше «от»; описание не длиннее 1200 символов; ввод работодателя показывается как **текст**, без интерпретации HTML.
6. **Публикация**: после предпросмотра единственный запрос POST /api/employer/vacancies создаёт вакансию. Кнопка блокируется на время запроса, чтобы не создавать дубли; при ошибке остаётся возможность повторить.
7. **Совместимость**: API и таблица `vacancies` не меняются. Три раздела объединяются в существующий `description` со строковыми заголовками и разрывами строк. Старые вакансии продолжают открываться и обрабатываться как прежде, включая поиск, отклики, согласие соискателя и демо-знакомства.

## Принятие
- Кнопка «Опубликовать» недоступна, пока не открыт предпросмотр.
- Пустые обязательные поля или несогласованный диапазон зарплаты блокируют предпросмотр.
- В предпросмотре видны обязанности, требования и условия; HTML-подобные строки отображаются буквально.
- Изменение поля отменяет предпросмотр; повторный предпросмотр показывает новую версию.
- На смартфоне (390 px) форма не имеет горизонтальной прокрутки.
- Созданная вакансия присутствует в списке работодателя и открывается в публичном поиске с форматированными разделами.
- Публикуется ровно одна вакансия, старая цепочка отклик → согласие → демонстрационное знакомство работает.
- Пройдены API-тесты и сквозной браузерный тест. Дополнительно требуется ручная проверка на Timeweb перед завершением релиза.

## Что не входит
- Реальные контактные данные; подключение оплаты; реальные рассылки; изменения хранилища/миграции; платные генеративные модели.
- Редактирование уже опубликованной вакансии и локальные черновики — отдельные будущие задачи, не включать без согласования.
