# Маршруты СТАЖНО — практические планы действий

Цель: существующие три маршрута становятся полезными инструментами до регистрации. Десять редакционных заданий, отметки выполнения, прогресс и переход к следующему шагу. Ссылки на опубликованные статьи, вакансии и сообщество сохраняются.

Отметки хранятся только в localStorage текущего браузера; нет новой серверной записи, аналитических событий отметок, персональных полей или синхронизации аккаунтов. Каждый ключ шага включает отпечаток текущего учебного материала и задания. Скрытые шаги не учитываются, новая редакция требует новой отметки. У каждого шага отдельный ключ с редакционным отпечатком. Сброс удаляет отметки только видимой редакции маршрута; старая вкладка не перезаписывает отметки новой. Недоступное хранилище явно обозначается, несохранённые действия остаются только в памяти открытой вкладки. Старые редакции не отображаются и не учитываются; их записи можно удалить очисткой данных сайта в браузере. Задания и ссылки доступны без JavaScript. При возврате из BFCache обновляются только локальные отметки для уже открытой редакции, без сетевого запроса и повторного события просмотра. Новое открытие маршрута получает текущий опубликованный материал; ранее открытая вкладка может содержать предыдущую редакцию. Старые закладки и прогресс Академии не меняются.

Проверка: клавиатура, мобильный крупный текст, повторное открытие, вкладки, разные маршруты, сброс, испорченная запись, недоступное хранилище, изменение и отзыв редакционного материала, отсутствие новых запросов записи. Домен, SMTP, тариф Timeweb, регистрация, платные функции и юридический режим не изменяются.
