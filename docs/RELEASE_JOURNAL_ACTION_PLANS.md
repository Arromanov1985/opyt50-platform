# Маршруты СТАЖНО — практические планы действий

Цель: существующие три маршрута становятся полезными инструментами до регистрации. Десять редакционных заданий, отметки выполнения, прогресс и переход к следующему шагу. Ссылки на опубликованные статьи, вакансии и сообщество сохраняются.

Отметки хранятся только в localStorage текущего браузера; нет новой серверной записи, аналитических событий отметок, персональных полей или синхронизации аккаунтов. Каждый ключ шага включает отпечаток текущего учебного материала и задания. Скрытые шаги не учитываются, новая редакция требует новой отметки. Сброс удаляет запись текущего маршрута; недоступное хранилище явно обозначается. Задания и ссылки доступны без JavaScript. Старые закладки и прогресс Академии не меняются.

Проверка: клавиатура, мобильный крупный текст, повторное открытие, вкладки, разные маршруты, сброс, испорченная запись, недоступное хранилище, изменение и отзыв редакционного материала, отсутствие новых запросов записи. Домен, SMTP, тариф Timeweb, регистрация, платные функции и юридический режим не изменяются.
