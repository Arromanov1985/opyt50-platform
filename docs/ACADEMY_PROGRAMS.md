# Образовательные программы Академии

## Редакционный план первой программы

**Цифровые навыки для работы** — для взрослых, начинающих осваивать
повседневные цифровые инструменты.

1. «Электронные таблицы с нуля» — 95 минут, 6 уроков: подготовка ведомости,
   вычисления, фильтры, проверка результата, отчёт. Черновик — PR #170.
2. «Искусственный интеллект с нуля» — существующий курс, 6 уроков:
   постановка задач, проверка ответов, безопасная работа с информацией.

Итоговая цель — самостоятельно подготовить небольшой рабочий отчёт
на вымышленных данных и использовать ИИ для подготовки черновика,
с обязательной ручной проверкой.

## Активация и границы

В конструкторе администратора выбрать «Готовый редакционный курс:
Электронные таблицы с нуля» и нажать «+ Новый курс». Один раз создаётся
приватный черновик из проверенного JSON #170 со стабильным идентификатором
spreadsheets-basics; повторный выбор открывает сохранённую версию без
перезаписи, в том числе скрытую. Обычные авторы не имеют этой опции.
Проверить содержание в предпросмотре, затем отдельно подтвердить
публикацию. При публикации исходного черновика без изменений (редакция 2)
и наличии исходного курса ai-basics (редакция 1) программа автоматически
появится в каталоге. До этого не появляется ни в каталоге, ни в sitemap.
Если редактор изменит содержание, потребуется проверить и явно закрепить
новую опубликованную редакцию в `app/academy_programs.py`.
Порядок задаёт редакция, не алгоритм категорий. Минимум два разных курса,
максимум двенадцать. Никакая публикация не производится автоматически.

Если любой курс отозван, скрыт, утратил право публичного отображения
или опубликован в другой редакции, вся программа недоступна, пока
редакция не проверит и не утвердит новую конфигурацию.
Несохранённые или приватные черновики не влияют на доступность.
Каталог, ссылки на курсах/уроках, страница программы, sitemap и release
manifest строятся из одного разрешённого набора.

Программа не создаёт новую сущность прогресса: вычисляет количество
завершённых курсов и уроков по существующим revision-scoped записям
в браузере, предлагает первый незавершённый урок в заданном порядке.
Курсы не блокируются искусственно; обучение добровольное. Никакой
регистрации, сертификатов, новой персональной статистики, внешних API
или платных сервисов. Без JavaScript остаются обычные ссылки на курсы.
Юридические и мультимедийные блокировки не меняются.

Проверки: реальные публичные маршруты и manifest в тестовой БД,
закрепление редакций, обязательная проверка всех доступных программ в
manifest по точным публичным версиям, отсутствие программы при скрытии курса, два курса
и общий прогресс в браузере, обновление между вкладками, повтор,
адаптивность, проверка Timeweb только разрешённых маршрутов.

Дополнительная приёмка: контрольная сумма опубликованного релиза включает
байты поставляемого JSON редакционного курса, поэтому изменение только
учебного материала также требует проверки Timeweb. Полная замена курса
через ИИ запрещена и на сервере, если сохранённый черновик содержит
прикреплённые файлы: сначала автор осознанно отсоединяет их и сохраняет
черновик либо добавляет отдельный урок. Существующая опубликованная
версия при проверке не меняется.
