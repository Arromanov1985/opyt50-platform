# СТАЖНО — редакционный релиз и подготовка закрытого пилота

Дата: 19 ноября 2026. Статус: функциональный тестовый выпуск. Боевой запуск и публикация настоящих данных пользователей этим документом не разрешены.

## Цель

Три равноправных сценария СТАЖНО: вакансии, профессиональные связи и полезные материалы. Первая редакция журнала — десять самостоятельных практических статей без вымышленных историй конкретных людей, поддельных отзывов или обещаний гарантированной работы.

## Редакционный процесс

- Через /admin/journal и /api/admin/journal авторизованный администратор создаёт черновик, редактирует, просматривает, публикует или снимает статью с публикации.
- У опубликованной статьи правка остаётся в черновике до новой публикации. Другая вкладка с устаревшей версией не может перезаписать редакцию.
- Неопубликованный черновик можно архивировать, опубликованную статью — скрыть. Действия регистрируются с версией, временем и идентификатором администратора.
- Только опубликованные версии видны в журнале, рекомендациях, sitemap и на главной. Предпросмотр и черновики в публичном API отсутствуют.
- Текст редактируется без HTML: заголовки начинаются с ##, абзацы — обычный текст, списки с - . Публичный вывод экранирован.
- Статьи в существующем каталоге сохраняются при повторной инициализации БД, личные данные пользователей для контента не используются.

## Подготовка пилота

Пилот пока не запущен. После юридической и эксплуатационной приёмки ориентир: 30–50 добровольных участников и 5–10 работодателей. Не создавать в живой БД вымышленные регистрации для имитации спроса.

Проверять отдельно понятность регистрации, переходы между разделами, реальные отклики, принятие знакомств, жалобы и обращения, время ответа модератора, причины ухода и повторных визитов. Цифры посещений не равны уникальным пользователям или наймам.

До приглашения реальных участников должны быть утверждены правила сервиса, реквизиты действительного оператора персональных данных, сроки хранения, политика обработки данных и процесс удаления. Платежи не включать.

## Откат

Новые таблицы редактора аддитивны. При проблеме откатывать код без массового удаления редакционной базы. Скрытые статьи и пользовательские правки не должны восстанавливаться автоматически при следующем старте.
