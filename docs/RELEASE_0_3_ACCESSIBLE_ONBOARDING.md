# Релиз 0.3.0-dev — удобное начало для соискателей 50+

## Цель
Сократить число действий на первом визите, увеличить читаемость и сохранить право человека самому решать, когда создавать профиль и кому раскрывать контакты. Возраст пользователя не запрашивается и не влияет на подбор.

## Реализовано в первой итерации
1. Кнопка «Посмотреть вакансии» на главной **не открывает регистрацию** — гость может изучить тестовые вакансии и фильтры без учётной записи. Отдельная кнопка «Создать профиль» остаётся.
2. В окне регистрации ясная подсказка о минимальном наборе данных; фокус начинается с поля имени и фамилии.
3. У кандидата профессия, город, навыки, желаемая зарплата и график доступны сразу. Остальные сведения (занятость, телефон и описание опыта) — в раскрываемом блоке, который можно заполнить позже. Все существующие имена полей и API остаются прежними, правила сохранения профиля не меняются.
4. После формы — прямые переходы к рекомендациям и истории откликов. Если персональных рекомендаций нет, есть понятный возврат к профилю и переход к публичному поиску.
5. Кнопка «Крупный текст» увеличивает размеры ключевых элементов, показывает состояние через `aria-pressed`; сохраняет **только выбранный режим оформления** в локальном браузере. Данные соискателя в браузерное хранилище не записываются.
6. На телефоне появляется короткая навигация по разделам сайта, кнопки кабинета раскладываются по сетке без горизонтальной прокрутки; интерактивные элементы имеют видимый фокус и достаточную высоту.
7. Цвета бренда (тёмно-синий #083664, яркий синий #007FCE, бирюзовый #00C7B8), логотип и существующие правила согласия на передачу контактов сохранены.

## Вторая итерация: помощник описания опыта
- В основной анкете постоянно видна кнопка «Помочь описать опыт →»: одно нажатие раскрывает оба дополнительных раздела и переводит фокус в первый вопрос. Не нужно искать помощник внутри двух скрытых панелей.
- Дополнительный раскрываемый помощник задаёт три коротких вопроса: направление работы, задачи и сильные стороны.
- Формулировки собираются детерминированно из введённых кандидатом фраз, без генерации выдуманного стажа и без внешних ИИ/API.
- Подсказки предлагают не вводить настоящие контактные данные; помощник отклоняет похожие на email или телефон строки.
- Текст сначала выводится в предварительном просмотре; добавляется только по отдельной кнопке, никогда не удаляя уже заполненное описание.
- Повторная вставка тех же предложений не создаёт дубли. Лимит 700 символов учитывается до изменения формы.
- Запись в базу происходит только при отдельном нажатии «Сохранить профиль»; помощник не вызывает API сам.
- Уведомление о сохранении помещается внутри ширины браузера, включая узкий экран.

## Критерии тестирования
- Без входа можно открыть поиск вакансий, фильтровать и посмотреть описание.
- Крупный текст включается/выключается клавиатурой и мышью и сохраняется после обновления.
- Регистрация начинает ввод с имени, основные поля профиля доступны без пролистывания всех дополнительных разделов.
- Существующий демонстрационный кандидат сохраняет профиль; дополнительные поля присутствуют в запросе и не теряются после сворачивания.
- На ширине 390 px меню и разделы кабинета доступны, не требуют мелких кнопок.
- Помощник не заменяет введённые данные и не отправляет сообщения при составлении текста; после явного сохранения описание доступно при повторном открытии профиля и перезагрузке браузера (F5).
- Регрессия релиза 0.2: избранное, отклик/отзыв/повторная подача, согласие кандидата, демонстрационное открытие контакта, администратор.

## Ограничения и дальнейшие релизы
- Это интерфейсный предварительный релиз `0.3.0-dev`, не производственная готовность.
- Не подключать реальные письма, SMS, платежи, персональные данные и внешние платные сервисы.
- На следующей итерации отдельно тестировать пользовательские сценарии с реальными представителями аудитории 50+ (с вымышленными данными), качество объяснения рекомендаций, доступность с клавиатуры и на экранных дикторах.
- Переход к настоящим клиентам возможен только после полноценной политики персональных данных, устойчивого хранилища, безопасности аккаунтов и отдельного согласования.
- Разработка в `feature/release-0.3-accessible-onboarding`; `main` и текущий Timeweb не меняются до приёмки.
