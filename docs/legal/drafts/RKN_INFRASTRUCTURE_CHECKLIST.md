## 3. Территория и провайдеры

Для каждого компонента заполнить фактический регион размещения БД, резервной копии и логов; документальное основание, срок, права администратора, возможный трансграничный поток и договор обработки:

- [ ] Timeweb App Platform — дата-центр, приложение, балансировщик, системные журналы.
- [ ] PostgreSQL — дата-центр, резервные копии, доступ операторов/поддержки.
- [ ] Служебная почта — очередь, SMTP, логи, хранение отправленных писем.
- [ ] Мониторинг, CDN/WAF, DNS, статистика, отправка ошибок.
- [ ] GitHub CI — не должны передаваться настоящие ПД пользователей; проверить artifacts/logs.
- [ ] Подрядчики с доступом к данным, включая удалённый доступ.

## 4. Регламенты

- [ ] Политика ПД и подтверждённые основания обработки.
- [ ] Хранение по категориям, резервные копии, удаление и журналирование запросов.
- [ ] Права доступа, учёт администраторов, MFA, обучение и аудит.
- [ ] Порядок реагирования на инциденты и сроки обязательных уведомлений.
