# Надёжный поиск вакансий

Каждый запуск поиска фиксирует введённые условия и контекст текущего аккаунта до асинхронных запросов. Только последний запрос может обновить карточки, счётчик, фильтры и ошибку. При смене аккаунта устаревший ответ игнорируется; вспомогательные запросы статусов откликов и избранного также защищены по очередности и владельцу. Вытесненный запрос дожидается актуальной загрузки, прежде чем обработчик отправленного отклика обновит кнопки и подтверждение. Отправленный отклик не должен выглядеть как новый до завершения более свежей загрузки. При начале поиска прежние карточки и кнопки скрываются, чтобы не показать несоответствующие условиям действия. Пока условия редактируются, отдельное сообщение объясняет, что изменения ещё не применены. Убрана двойная обработка Enter в поле города. Ошибка загрузки отличается от отсутствия результатов и предлагает повтор.

Сценарии браузерной регрессии: управляемый порядок старого и нового ответов (успешный старый ответ и старый HTTP 503), загрузка, неприменённые фильтры, ошибка последнего запроса, повтор и сброс. Не меняются API, алгоритм подбора, сохранённые поиски, отклики, приглашения, права доступа и инфраструктура. Новых платных ресурсов нет.
