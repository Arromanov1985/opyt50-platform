# 0.2.1.2 — точный подбор профессий и понятный повторный отклик

## Обнаружено при ручной приёмке
- Кандидат «Бухгалтер» видит рекомендацию «Инженер по эксплуатации» с совпадением 60%. Общий навык `Excel` не означает квалификацию по инженерной специальности.
- В карточке вакансии отображается активная кнопка «Откликнуться» даже если пользователь уже подавал отклик. При повторном нажатии сервер возвращает 409 «Вы уже откликались…». Это правильная серверная защита от дублей, но плохой интерфейс.

## Исправления
1. Для **персональных рекомендаций** и подбора кандидатов работодателем требуется пересечение значимых слов профессии кандидата с названием вакансии. При отсутствии такого пересечения вакансия не рекомендуется независимо от общих программ вроде Excel. Остальные фильтры: город/удалённость, зарплата, график, тип занятости, навыки — сохранены.
2. **Публичный поиск** по всем открытым вакансиям работает как прежде и не блокирует смену профессии; неподходящую вакансию можно найти самостоятельно.
3. В карточке вместо «Откликнуться» после подачи появляется «Отклик: Отправлен · история» (или соответствующий статус). Кнопка ведёт в раздел «Мои отклики».
4. После отзыва появляется «Откликнуться повторно»; сервер использует ранее существовавшую заявку и журналирует повторную подачу.
5. Окно подробностей вакансии также отображает статус текущего отклика, а не новую кнопку.
6. При устаревшей вкладке, если сервер возвращает конфликт уже существующего отклика, UI обновляет данные и открывает историю вместо сообщения об ошибке.

## Критерии приёмки
- Профиль «Бухгалтер», Москва, `Excel`: вакансия «Бухгалтер» рекомендуема, «Инженер по эксплуатации» не рекомендуема.
- Профиль «Инженер»: «Инженер по эксплуатации» рекомендуема.
- Отправить отклик можно один раз, повторное нажатие не предлагается интерфейсом; сервер запрещает дубликат.
- После отзыва можно повторно отправить отклик; статус и история обновляются.
- Ранее проверенные 0.2.1 сценарии «согласие → демо-знакомство» и административные функции сохранены.
- Возраст не влияет на алгоритм; настоящие персональные данные/почта/платежи не подключены.
- Ветка `feature/release-0.2-relevant-matches` создаётся для ревью; main и Timeweb остаются без изменений.

## Ограничение первой версии
Это консервативный лексический фильтр профессии, а не полноценная семантическая модель. Он предотвращает наиболее очевидные ложные совпадения, но пока может пропускать близкие названия профессий, синонимы и карьерные переходы. Расширение и прозрачные объяснения совпадений запланированы отдельно.
