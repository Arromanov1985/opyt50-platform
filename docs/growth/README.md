# СТАЖНО — закрытый growth-пилот: рабочий комплект

**Статус: DRAFT / НЕ ДЛЯ ПУБЛИЧНОГО НАБОРА.** Последняя техническая база — PR #108, коммит `017eb09`. Подготовлено 20.11.2026 для issue #95.

Это инструменты исследования гипотезы **«полезный материал → осмысленное действие → профессиональный контакт по взаимному согласию»**, а не разрешение на рекламную кампанию.

## Состав пакета

1. [План на 30 дней](PILOT_30_DAY_PLAN.md) — приоритеты и контрольные решения по неделям, ресурсы, условия старта.
2. [Интервью с кандидатами и работодателями](INTERVIEW_GUIDES.md) — нейтральные вопросы, сценарий, обезличенные заметки и кодировка причин отказа.
3. [Приглашения и сообщения партнёрам](INVITATION_TEMPLATES.md) — тексты для персональных контактов после допуска, без обещаний трудоустройства или массовых сообщений.
4. [Портфель из 12 редакционных тем](EDITORIAL_BACKLOG_12.md) — запрос читателя, польза, контент-структура, релевантное действие и проверки фактов.
5. [Сводная карточка пилота](SCORECARD_AND_DECISIONS.md) — измерения из существующего API и вручную подтверждаемые результаты, ограничения атрибуции, правила решений.

## Непреодолимый барьер перед реальным набором

Issue [#98](https://github.com/Arromanov1985/opyt50-platform/issues/98) открыт. Подготовленный [PR #99](https://github.com/Arromanov1985/opyt50-platform/pull/99) содержит **тестовый**, а не действующий юридический пакет на «ИП Иванов Иван Иванович». До настоящего подтверждения оператора, документов, локализации ПД, процедур обращений и юриста **не приглашать реальных людей регистрироваться, не запускать рассылки, не публиковать свидетельства и не продвигать Timeweb как готовый сервис**.

Допустимы внутреннее редактирование текстов, UX-тесты на синтетических данных, проверка логики и составление списков потенциальных каналов **без публикации персональных данных в репозитории**. При любых противоречиях приоритет имеют требования законодательства и утверждённые оператором процедуры. Этот комплект не является юридическим заключением.

## Важные ограничения

- Тестовый Timeweb-домен не переносим на основной без отдельного решения.
- Не добавляем рекламные пиксели, cookie-трекинг, UTM-профили посетителя, массовую почту или платёжные механизмы.
- В GitHub фиксируем только обезличенные итоговые коды/числа, не ФИО, телефоны, email, прямые цитаты или записи интервью.
- Сохраняем крупный шрифт и мобильную доступность при будущей реализации.
- Результаты собеседований и трудоустройства **нельзя** выводить из демо-открытий контактов автоматически.
