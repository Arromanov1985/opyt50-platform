## 1. Код в GitHub

Адрес репозитория: https://github.com/Arromanov1985/opyt50-platform

На 08.10.2026 в нём был только начальный README. Сначала перенесите туда файлы из этого архива, включая Dockerfile, app/, scripts/, deploy/, requirements.txt.

**Самый простой способ:** распакуйте архив в отдельную папку Windows и запустите PowerShell в ней:

```powershell
powershell -ExecutionPolicy Bypass -File .\PUBLISH_GITHUB.ps1
```

Скрипт сам клонирует существующий GitHub-репозиторий в новую временную папку, копирует исходники, создаёт коммит и выполняет обычный `git push` без принудительной перезаписи истории. Если GitHub попросит авторизацию, войдите через собственный браузер. Скрипт не запрашивает пароль GitHub.

**Альтернативный ручной способ:** в Git Bash на своём ПК (в выбранной рабочей папке):

```bash
git clone https://github.com/Arromanov1985/opyt50-platform.git
```

Распакуйте данный архив отдельно и скопируйте ВСЁ его содержимое в папку, созданную `git clone`, заменив README.md. **Не удаляйте папку `.git` в клоне**. Затем выполните в папке клона:

```bash
git add -A
git commit -m "feat: first OpyT 50+ MVP and Timeweb preview"
git push origin main
```

Рекомендуется перед этим переключить репозиторий в **Private**. В любом случае не добавляйте `.env`, токены, реальные телефоны или SQLite-БД.

## 2. Создать приложение в Timeweb Cloud

Это НЕ панель обычного виртуального хостинга Timeweb. Используйте Timeweb Cloud: https://timeweb.cloud/

1. Войдите в Timeweb Cloud -> **App Platform -> Добавить**.
2. Выберите приложение на **Dockerfile** (наш Dockerfile содержит `EXPOSE 8000`).
3. Подключите **GitHub через кнопку авторизации**, а не по URL. Подключение через GitHub нужно для автодеплоя.
4. Укажите репозиторий `Arromanov1985/opyt50-platform` и ветку `main`.
5. Оставьте включённым автоматический деплой **по последнему коммиту**.
6. Выберите минимальную подходящую конфигурацию в регионе РФ; проверьте её стоимость до заказа.
7. В расширенных настройках задайте переменные окружения:

   - `OPYT50_COOKIE_SECURE=1`
   - `OPYT50_PREVIEW_USERNAME=review`
   - `OPYT50_PREVIEW_PASSWORD=...` — **придумайте длинный уникальный пароль**, введите в личном кабинете, не в GitHub.
   - `OPYT50_PREVIEW_SEED_DEMO=1`

8. Для проверки состояния укажите путь `/api/health`, если есть соответствующее поле.
9. Запустите деплой. Дождитесь статуса «Готово»; появится бесплатный тестовый домен с HTTPS.

По запросу на сайт браузер предложит логин `review` и пароль из настроек. Только после этого доступно тестирование.

Демо-аккаунты *внутри приложения* (отличаются от пароля на вход в тестовый стенд):

- `company@demo.example` / `DemoPass2026!` — работодатель
- `kladovshik@demo.example` / `DemoPass2026!` — соискатель
- `admin@demo.example` / `DemoPass2026!` — администратор

Никаких реальных оплат нет. Тестовые телефоны и имена вымышлены.

## 3. Как выглядит процесс разработки

Каждый новый коммит в `main` автоматически запускает сборку и обновляет тестовую ссылку. Если обновление неудачное, на странице приложения в Timeweb Cloud будет лог деплоя.

**ВАЖНО:** SQLite внутри контейнера в этой версии — временная демонстрационная БД. После обновления контейнера данные могут исчезнуть. Это нормально ТОЛЬКО для вымышленной демобазы. Для работы с реальными людьми сначала перейти на внешнюю PostgreSQL, настроить HTTPS, юридические согласия, резервное копирование, защиту от злоупотреблений и аудит безопасности.
